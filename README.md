# 找娃助手 (kid-finder)

从幼儿园老师发在微信班级群 / 群相册里的海量照片和长视频中，自动找出**自家宝宝**的照片与出场视频片段，并自动留存写有宝宝名字的作品照。

## 核心特性

- **100% 本机离线识别，零封号风险**：人脸检测识别（InsightFace + ONNX Runtime）与作品文字识别（PP-OCR ONNX）全部在本机运行，照片与视频绝不上传云端，也绝不读取微信进程内存或改动微信内部目录
- **人脸 + 作品署名双留存**：录入宝宝正脸照的同时填写**姓名与小名/署名**（三字/四字姓名自动推导双字名，支持常见起名生僻字与竖排落款），不仅能找出露脸照，还能自动识别并留存没有露脸但写有宝宝名字的**画作、手工、奖状**
- **照片与视频独立工作台**：统一导入后自动分流到 **「③ 宝宝照片」**（支持筛选人脸照 / 作品署名照、一键批量导出无损高清原图）与 **「④ 宝宝视频」**（自动定位宝宝出场时间段、配置前后缓冲与淡入淡出、逐段试看微调并裁剪导出）
- **微信 4.x 安全批量导入与原位扫描**：提供针对新版电脑微信 4.x 实测验证的平铺多选批量保存指引，内置**本机微信明文视频目录原位零拷贝扫描**与 **「微信中转监听文件夹」** 自动后台入库
- **内置 Chrome 扩展（`qxc.hi.cn`）**：可在群相册网页版直接调用本机模型**增量扫新增**、自动勾选命中照片（含作品署名照）并自动裁剪命中视频，复用桌面端已录入的宝宝档案，无需全量下载全班原图
- **存储目录迁移与空间瘦身**：支持在「设置」中将媒体库经 SHA-256 校验一键迁移到大容量磁盘/移动硬盘，以及一键清理无娃原片（释放磁盘空间但保留几 KB 指纹记录，以后绝不重复导入重扫）
- 支持 Windows（x64）与 macOS（Apple Silicon），内置签名自动更新

## 快速使用

1. **设置（首次准备）**：首次打开先一键下载离线人脸与作品识字模型；若需分析与裁剪视频，再点「自动安装」配置 `ffmpeg`（macOS 也可执行 `brew install ffmpeg`）。
2. **① 录入宝宝**：新建宝宝并添加清晰正脸照（1 张即可用，建议 3~10 张不同角度/光线更稳），同时填写**姓名与小名/署名**以自动留存画作、手工、奖状等署名作品。
3. **② 导入照片视频**：支持选入/拖入本地文件夹（按 `SHA-256` 内容指纹秒级去重）：
   - **从电脑微信（4.x）班级群批量导入（实测可行 · 100% 零封号）**：
     > 新版微信 4.x 群图片底层为动态加密 `.dat` 且未点开的原视频在本地只有封面图；强行读微信内存解密有封号风险，本软件绝不触碰微信进程。同时注意：微信 4.x 拖拽采用虚拟流协议，**不要直接从微信窗口拖向本软件窗口**，请按以下 4 步批量导出：
     1. **建中转夹**：新建一个空文件夹（如 `微信导出中转`），建议在「② 导入照片视频」绑定为 **「微信中转监听文件夹」**（保存完自动入库；也可手动选入文件夹）；
     2. **平铺并开多选**：在电脑微信打开班级群 → 点右上角 **`...`** → 点 **「聊天记录」** → 切换到 **「图片与视频」** 标签页（折叠多图会自动全部平铺展开）→ **在任意缩略图上点鼠标右键 → 选「多选」**；
     3. **拉框勾选点底部「保存」**：按住鼠标左键拖动拉框勾选（微信单批上限 **100 项**，几百张分 2～3 批即可；`Ctrl+A` 与右键批量另存在微信 4.x 中均无效）→ 点击窗口**最底部操作栏第 5 个「保存」图标**（收藏右边、删除左边）→ 选第 1 步的中转文件夹，微信会自动从云端拉取未下载的高清原图与完整 `.mp4` 原视频并解密写出；
     4. **找娃后即清空间**：识别并导出自家娃的照片和精华视频片段后，**中转文件夹可直接清空**（指纹已永久记录，下次选重也会秒级跳过）；微信自身下载缓存的大视频可在微信左下角 `≡` → **「设置 → 存储空间 → 聊天数据『管理』」** 安全清理。此外，开启微信「设置 → 账号与存储 → 自动下载在其他设备查看过的内容」后，手机上看过的群视频会自动同步到电脑微信明文目录，支持在找娃助手里**一键原位零拷贝扫描**。
   - **从「群相册」小程序 / 网页版导入**：可在桌面端扫码一键增量同步相册（登录有效期 24 小时），或点击左下角 **「安装 Chrome 扩展」** 在 `qxc.hi.cn` 浏览器里直接增量扫新增、自动勾选照片（含作品署名照）并自动裁剪命中视频。
4. **③ 宝宝照片 & ④ 宝宝视频**：
   - **纠错越用越准**：在结果里点 `✓` 会把该人脸补充进参考照，点 `✕` 会立即排除误判人脸或作品；参考照或名字增删改后会自动毫秒级重算结果。
   - **照片原图导出**：在「③ 宝宝照片」按需调节严格程度或切换「全部 / 人脸照 / 作品署名」筛选，一键导出选中高清原图。
   - **视频精华裁剪**：在「④ 宝宝视频」可设置「宝宝出现前提前 N 秒 / 离开后多留 N 秒 / 淡入淡出」，点击时间胶囊试看，或点开视频逐段修改起止时间（输入 `分:秒` 或暂停点「设为起点/终点」），只导出有自家娃的片段。
5. **磁盘空间管理（设置页）**：
   - **一键迁移媒体库**：将本地媒体与缩略图目录经 SHA-256 校验安全迁移到其他大容量磁盘或外接移动硬盘；
   - **一键清理未命中原片**：清理托管媒体库中未命中任何已录入宝宝的原图/原视频以释放空间（绝不触碰外部目录原片），同时保留几 KB 文件指纹记录，避免日后重复导入重扫。

## 下载

到 [Releases](https://github.com/melotusme/kid-finder/releases/latest) 下载对应平台安装包：

- **Windows**：`kid-finder_*-setup.exe`
- **macOS（13.4 及以上，Apple Silicon）**：`kid-finder_*.dmg`。应用未经 Apple 公证签名，首次打开若提示「已损坏」，请在终端执行：
  ```bash
  xattr -cr /Applications/找娃助手.app
  ```

## 开发

```bash
npm install
npm run tauri dev
```

需要 Node 20+ 和 Rust stable。数据（数据库、模型、导入的媒体）默认存放在系统应用数据目录，可在「设置」页打开或一键迁移到其他磁盘。

## 发布

推送 `v*` tag 触发 GitHub Actions 构建并发布跨平台签名 Release（含自动更新清单 `latest.json`）。
需要在仓库 Secrets 中配置 `TAURI_SIGNING_PRIVATE_KEY` 和 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`。
发版前请同步更新 `package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml` 以及 `chrome-extension/manifest.json`（桌面端与内置扩展需保持 `major.minor` 基线一致）。
